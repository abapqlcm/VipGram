# VipGram 🚀

تلگرام مود شده (modded) اندروید — بر پایه سورس رسمی [Telegram for Android](https://github.com/DrKLO/Telegram) (نسخه ۱۲.۱۰.۱).

هدف: یه کلاینت تلگرام شخصی با چند تا قابلیت که نسخه رسمی نداره (یا محدود کرده)، بدون تغییر در سرور — یعنی همه‌چیز فقط در سمت کلاینت (اپ شما) اعمال می‌شه.

---

## 📱 چی هستش (مودها)

همه مودها توی فایل `BuildVars.java` به صورت فلگ (boolean) کنترل می‌شن. پچ کامل توی `vipmod.patch` هست.

| # | قابلیت | فلگ | چطوری کار می‌کنه |
|---|--------|-----|-------------------|
| 🛡️ | **ضدحذف پیام** | `NO_ADS_AND_KEEP_MESSAGES` | وقتی طرف مقابل پیام رو «برای همه» حذف می‌کنه، تلگرام دستور حذف رو از سرور می‌گیره ولی اپ شما اون رو نادیده می‌گیره (`continue`) → پیام نزد شما می‌مونه. هم برای چت‌های عادی و هم چنل‌ها (updateDeleteMessages + updateDeleteChannelMessages) اعمال شده. |
| 🚫 | **ضدتبلیغ (No Ads)** | `NO_ADS_AND_KEEP_MESSAGES` | دو تا جا: ۱) `promoDialogId` هرگز ست نمی‌شه (پس بنر پروکسی/PSA لود نمی‌شه) ۲) تابع `getSponsoredMessages()` برمی‌گردونه `null` → هیچ پیام اسپانسری توی هیچ چتی نشون داده نمی‌شه. |
| ⚡ | **بوست سرعت دانلود** | `SPEED_BOOST` | توی `FileLoadOperation`: تعداد درخواست‌های موازی دانلود از ۴ می‌ره بالا (۱۲ درخواست موازی) + سایز چانک از ۱۲۸KB می‌ره بالا (۵۱۲KB) → دانلود فایل‌های بزرگ سریع‌تر. |
| ⚡ | **بوست سرعت آپلود** | `SPEED_BOOST` | توی `FileUploadOperation`: سایز چانک آپلود ×۸ بزرگتر (۲MB بجای ۲۵۶KB) + **سقف واقعی ۱۶ درخواست موازی** (`Math.min(16, ...)`). باگ قبلی: چون چانک ۶۴KB بود، ۲۵۶ درخواست موازی می‌فرستاد که سرور رو فلاد می‌کرد و آپلود کیلوبایتی می‌شد — فیکس شد. |
| 📸 | **آزادسازی اسکرین‌شات** | `NO_SCREENSHOT_RESTRICTION` | قفل اسکرین‌شات (`FLAG_SECURE`) در ۳ جا غیرفعال شد: ۱) چت‌های سکرت/noforwards (`ChatActivity`) ۲) ویوور مدیا (`PhotoViewer`) ۳) ویوور مدیای سکرت (`SecretMediaViewer`). یعنی می‌تونی از هر چیزی (حتی عکس تایمردار) اسکرین بگیری. |
| 🕒 | **عکس تایمردار بدون تایمر** | `KEEP_SELF_DESTRUCT_MEDIA` | وقتی عکس self-destruct (ttl) میاد: ۱) تابع `sendSecretMessageRead` برمی‌گردونه `null` → تایمر هیچ‌وقت استارت نمی‌خوره و به سرور خبر نمیره ۲) دکمه ذخیره/فوروارد بمونه می‌مونه (`galleryButton` مخفی نمیشه). یعنی عکس باز می‌شه، بمونه، و می‌تونی سیو/اسکرین بگیری بدون اینکه طرف مقابل بفهمه. |
| ⭐ | **پرمیوم لوکال (جعلی)** | `LOCAL_PREMIUM_LOOK` | ستاره پرمیوم رو برای **حساب خودت** نشون می‌ده (بدون اینکه واقعاً پرمیوم باشی). توی `putUser` وقتی اکانت شما باشه، `user.premium = true` ست می‌شه + توی `UserConfig.isPremium()` برمی‌گردونه true → ستاره تو پروفایل و لیست چت‌ها میاد. فقط ظاهریه، هیچ قابلیت پرمیومی (مثل آپلود بزرگتر) باز نمی‌کنه. |
| 👻 | **گوست استوری** | `GHOST_STORY` | وقتی استوری رو می‌بینی، محلی علامت می‌خوره (seen) ولی به سرور گزارش **نمیشه** (`TL_stories_incrementStoryViews` زده نمیشه) → طرف نمی‌فهمه استوری‌ش رو دیدی. |

| مورد | مقدار |

به دلیل package name متفاوت، VipGram **کنار تلگرام اصلی** روی یه گوشی نصب می‌شه و تداخلی ندارن.

## 🔧 چطوری کار می‌کنه (معماری)

```
┌─────────────────────────────────────────────┐
│  GitHub Actions (ubuntu-latest, JDK 21, NDK) │
│                                              │
│  1. کلون سورس رسمی تلگرام (DrKLO/Telegram)  │
│  2. اعمال vipmod.patch روی سورس              │
│  3. تزریق api_id / api_hash از Secrets         │
│  4. نصب SDK/NDK + کامپایل نیتیو (C++)        │
│  5. ./gradlew assembleAfatRelease             │
│  6. آپلود APK به عنوان Artifact               │
└─────────────────────────────────────────────┘
                    │
                    ▼
            📦 VipGram-APK (امضا شده)
```

**نکته امنیتی مهم:** `api_id` و `api_hash` شما **هیچ‌وقت** توی کد هاردکد نیستن. اونا به صورت **GitHub Encrypted Secrets** (`API_ID` / `API_HASH`) توی ریپو ذخیره می‌شن و فقط توی زمان بیلد، با دستور `sed` توی `BuildVars.java` تزریق می‌شن. توی لاگ‌های بیلد هم به صورت `***` ماسک می‌شن. پس ریپو حتی اگه public باشه، کلید شما لو نمیره.

## 🏗️ بیلد خودکار (GitHub Actions)

بیلد هیچ نیازی به کامپیوتر شما نداره — همه‌چیز روی سرورهای گیت‌هاب انجام می‌شه.

### trigger ها:
- **Push** به برنچ `main` (اگه `vipmod.patch` یا `.github/workflows/build.yml` تغییر کرده باشه)
- **workflow_dispatch** (دستی از تب Actions → Run workflow)

### مراحل (`build.yml`):
1. Checkout ریپو (جایی که `vipmod.patch` هست)
2. Clone سورس تلگرام + همه submodules (کامپایل نیتیو نیاز به همه‌شون داره)
3. اعمال پچ: `git apply vipmod.patch`
4. تزریق api از Secrets
5. Set up JDK 21 + Android SDK/NDK
6. کامپایل: `./gradlew :TMessagesProj_App:assembleAfatRelease`
7. جمع‌آوری APK از پوشه خروجی + آپلود به Artifacts

⏱️ زمان تقریبی بیلد: **۵۰-۶۰ دقیقه** (کامپایل کد نیتیو C++ سنگینه).

## 📥 نصب روی گوشی

1. برو به تب **Actions** ریپو → آخرین run موفق → بخش **Artifacts** → دانلود `VipGram-APK`
2. فایل zip رو باز کن → APK رو استخراج کن
3. APK رو روی گوشی نصب کن (اگه «منابع ناشناس» باز نیست، از مسیر تنظیمات فعالش کن)
4. اولین بار ممکنه چند ثانیه طول بکشه تا دیتابیس آماده بشه
5. با شماره خودت لاگین کن — کیف می‌کنی 😎

## 🛠️ توسعه / تغییر مودها

برای اضافه کردن یا تغییر یه مود:

1. فایل `vipmod.patch` رو ادیت کن (یا سورس رو کلون کن، تغییر بده، `git diff` بگیر)
2. پوش کن به `main` → بیلد خودکار شروع می‌شه
3. یا دستی: تب Actions → Run workflow

**نکات:**
- سورس تلگرام ~۳GB هست و بیلد به ۴-۸GB RAM نیاز داره → روی گیت‌هاب انجامش بده، نه لوکال (مگه سیستمت قوی باشه)
- اگه سورس رسمی آپدیت شد و پچ نخورد (conflict)، Actions ارور می‌ده → باید پچ رو با نسخه جدید ریبیس کنی
- فلگ‌های جدید رو حتماً توی `BuildVars.java` تعریف کن و import لازم رو چک کن

## ⚠️ نکات قانونی / اخلاقی

- این یه پروژه شخصیه و مسئولیت استفاده با خودته
- مودهای ضدحذف/گوست باعث می‌شه طرف مقابل نفهمه پیامش حذف/دیده شده — با اخلاق استفاده کن
- کلیدهای API از حساب شخصی خودته → هر اسپمی با اونا بشه به خودت برمی‌گرده
- امضای APK با کلید توسعه‌ای DrKLO هست (برای مصرف شخصی اوکیه، برای انتشار عمومی کلید خودت رو بساز)
